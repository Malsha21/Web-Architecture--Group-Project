Design a complete, modern, colorful, responsive educational web application called "EduLanka" for Sri Lankan primary school children.

PROJECT OVERVIEW:

EduLanka is a free interactive learning web application designed especially for Sri Lankan primary school children, including children in rural areas who have limited access to quality tutoring.

The platform provides simple, engaging and accessible educational resources covering:

- Mathematics
- Sinhala Letters
- English Alphabet
- General Knowledge
- Educational Games
- Interactive Quizzes

The application should be easy enough for young primary school children to use independently while also providing monitoring features for parents and teachers and content management features for administrators.

IMPORTANT LANGUAGE REQUIREMENT:

The DEFAULT interface language must be ENGLISH.

Users must be able to change the interface language using a clearly visible language selector:

English
සිංහල
தமிழ்

Do NOT display all three languages simultaneously throughout the UI.

English should be the default language.

When the user selects Sinhala, the interface should be designed to support Sinhala content.

When the user selects Tamil, the interface should be designed to support Tamil content.

Create the UI architecture so that multilingual content can be supported later through frontend and backend implementation.
