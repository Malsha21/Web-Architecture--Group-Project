22. VISUAL DESIGN SYSTEM
========================================

Create ONE consistent EduLanka design system across all pages.

The website should be:

- Colorful
- Modern
- Playful
- Friendly
- Educational
- Accessible
- Professional
- Clean

Use a cheerful combination of colors such as:

Bright blue
Yellow
Green
Orange
Purple
Pink

Use these colors as balanced accents rather than making every page completely different.

Use:

- Rounded cards
- Friendly icons
- Educational illustrations
- Clear buttons
- Large readable typography
- Consistent spacing
- Consistent border radius
- Consistent shadows
- Clear visual hierarchy

Do not make the UI overly childish or visually crowded.
